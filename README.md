While the minimum completion criterion requires **2 or 3 tasks**, I have **completed and documented all 4 tasks** in this repository to demonstrate end-to-end proficiency across the entire Data Analytics pipeline.

## Detailed Overview of All 4 Tasks

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>01. Task 1: Web Scraping</h3>
      <p><b>Goal:</b> Extract structured, custom datasets from public web pages by navigating HTML structures.</p>
      <ul>
        <li><b>Tools:</b> Python, BeautifulSoup, Scrapy, Requests.</li>
        <li><b>Workflow:</b> Inspected DOM elements, handled multi-page pagination, managed HTTP headers/rate limits, and parsed raw HTML tags.</li>
        <li><b>Deliverable:</b> Clean, structured dataset saved in <code>.csv</code> and <code>.json</code> formats ready for downstream analysis.</li>
      </ul>
      <p><b>Directory:</b> <code>./Task_1_Web_Scraping</code></p>
    </td>
    <td width="50%" valign="top">
      <h3>02. Task 2: Exploratory Data Analysis (EDA)</h3>
      <p><b>Goal:</b> Investigate dataset structure, validate assumptions, and uncover trends and anomalies.</p>
      <ul>
        <li><b>Tools:</b> Pandas, NumPy, SciPy, Jupyter Notebook.</li>
        <li><b>Workflow:</b> Formulated analytical questions, audited data types, treated missing values & outliers, and ran statistical hypothesis tests.</li>
        <li><b>Deliverable:</b> Comprehensive EDA notebook with statistical summaries and a cleaned dataset.</li>
      </ul>
      <p><b>Directory:</b> <code>./Task_2_Exploratory_Data_Analysis</code></p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>03. Task 3: Data Visualization</h3>
      <p><b>Goal:</b> Transform raw numbers into clear, compelling visual stories that support business decisions.</p>
      <ul>
        <li><b>Tools:</b> Matplotlib, Seaborn, Plotly, Tableau.</li>
        <li><b>Workflow:</b> Built univariate/multivariate charts, correlation heatmaps, time-series trends, and interactive dashboards.</li>
        <li><b>Deliverable:</b> High-resolution visual portfolio & dashboard exports highlighting actionable KPIs.</li>
      </ul>
      <p><b>Directory:</b> <code>./Task_3_Data_Visualization</code></p>
    </td>
    <td width="50%" valign="top">
      <h3>04. Task 4: Sentiment Analysis</h3>
      <p><b>Goal:</b> Classify text data into <b>Positive</b>, <b>Negative</b>, or <b>Neutral</b> sentiments to gauge public opinion.</p>
      <ul>
        <li><b>Tools:</b> NLTK, VADER, TextBlob, Scikit-Learn.</li>
        <li><b>Workflow:</b> Cleaned text (stopwords, lemmatization), computed polarity & subjectivity scores, and analyzed emotion distributions across reviews/social data.</li>
        <li><b>Deliverable:</b> NLP sentiment pipeline with word clouds and actionable product/marketing insights.</li>
      </ul>
      <p><b>Directory:</b> <code>./Task_4_Sentiment_Analysis</code></p>
    </td>
  </tr>
